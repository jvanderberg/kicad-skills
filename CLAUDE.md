# kicad-skills

Skills and tools for KiCad boards; each folder under `skills/` is a self-contained skill whose `SKILL.md` is the
instructions. When the plugin is not installed, read the relevant `SKILL.md` and follow it as you would a loaded
skill - these files are instructions, not background reading.

- **A new board** (from this repo or any other project that points here) starts with
  `skills/kicad-new-board/SKILL.md`, and its first step is the interview: your first reply is interview questions,
  before any part search, datasheet, reference design, repository or schematic.
- Schematics and boards: `skills/kicad-pcb-workflow/SKILL.md`. Reviews: `skills/kicad-board-review/SKILL.md`. Rails:
  `skills/pcb-power-supply/SKILL.md`. Batteries: `skills/pcb-battery-power/SKILL.md`. Parts:
  `skills/pcb-part-selection/SKILL.md`.
