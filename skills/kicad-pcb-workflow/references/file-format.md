# KiCad file format: what you need to edit it safely (KiCad 9/10)

Files are s-expressions, tab-indented, one token group per line. `scripts/sexp.py` has `block()` (balanced block that
respects quoted strings), `blocks()`, `find_ref()`, `kstr()` and a `check` command. Always edit the text with a script
that asserts each anchor matched exactly once.

## Strings

- **Never put a raw newline in a quoted string.** Write `\n` as the two characters backslash-n. A raw newline in a
  schematic text or property makes KiCad silently drop every item after it in that sheet - no error; ERC still runs;
  the symbols simply vanish from the netlist. Use `kstr()`; with `re.sub`, pass the replacement as a function
  (`lambda m: new`) so `\n` in it is not turned into a newline. `sexp.py check` finds these.
- Escape `"` and `\` inside strings. A board text ending in `\n` doubles its bounding box (silk overlap warnings).

## Board (`.kicad_pcb`)

- **Nets are referenced by name** (`(net "GND")`); KiCad 10 boards have no net table.
- **`/` in auto-generated net names is written `{slash}`**: `Net-(U1-EN/UVLO)` is stored as `Net-(U1-EN{slash}UVLO)`.
  Pad-net sync from a netlist must escape it (only inside `Net-(` and `unconnected-(` names), or DRC reports
  `net_conflict`.
- **Auto net names come from a pin** (`Net-(U1-GPIO35)`). Inserting a series part or swapping a connector renames
  nets; re-export the netlist and rename the board's nets to match, or parity reports
  `Pad net (X) doesn't match net given by schematic (Y)`.
- Track and via blocks that work (fresh uuid each):
  ```
  	(segment
  		(start x y)
  		(end x y)
  		(width w)
  		(layer "F.Cu")
  		(net "NAME")
  		(uuid "…")
  	)
  	(via
  		(at x y)
  		(size 0.6)
  		(drill 0.3)
  		(layers "F.Cu" "B.Cu")
  		(free yes)
  		(net "NAME")
  		(uuid "…")
  	)
  ```
- **`(free yes)` on stitching and thermal vias.** A via that touches only pours (no track) gets its net recomputed by
  KiCad on load/save; thermal vias on a power island can be re-netted to GND this way.
- **Insert top-level items at a top-level anchor**: `t.find('\n\t(segment\n') + 1` or `'\n\t(zone\n'`. A bare
  `'\t(zone'` can match a zone nested inside a footprint, and the new item lands inside the footprint.
- **Zones**: `(priority N)` layers pours (higher wins); `(island_removal_mode 1)` means never remove islands, so via
  fields can leave isolated copper; `(keepout ...)` rule areas silently clip pours - grep for `(keepout` before adding
  or growing a pour and edit the rule area's polygon if needed. Filled polygons are regenerated by a refill; edit the
  outline, not the fill.
- **Footprints on the board carry their own copy** of pads, fields and graphics. Changing the library does not change
  placed footprints (DRC `lib_footprint_mismatch` until updated). Properties (`LCSC`, `Datasheet`, ...) must match the
  schematic or parity complains: add hidden properties as text, e.g.
  `(property "LCSC" "C12345" (at 0 0 0) (layer "F.Fab") (hide yes) (uuid "…") (effects (font (size 1 1) (thickness 0.15))))`.
- **Footprint orientation**: in native orientation pad 1 of a two-pad part is at -x. With y pointing down, rotation 90
  puts pad 1 at +y (south); 270 north; 180 east. Check pad positions after placing.
- **Match by position with a tolerance** (`abs(a - b) < 0.02`): coordinates are written with varying decimals. Match
  board texts by text *and* position - the first `"GND"` in the file is rarely the one you want.
- A pcbnew save reformats the whole file (a one-line change can become a diff of thousands of lines); text edits keep
  diffs reviewable.

## Schematic (`.kicad_sch`)

- A placed symbol needs: the library symbol copied into the sheet's `(lib_symbols ...)` as `"Lib:Name"`; the
  `(symbol (lib_id "Lib:Name") (at x y rot) (unit 1) ... (uuid …)` block with every property; one `(pin "N" (uuid …))`
  per pin; and `(instances (project "name" (path "/<root-uuid>/<sheet-uuid>" (reference "R1") (unit 1))))`. Get the
  sheet path from the root sheet's `(sheet ... (uuid …))`; a wrong path silently drops the reference.
- Insert new items before `\n\t(sheet_instances`, else `\n\t(embedded_fonts`, else the final `\n)` - KiCad 10
  sub-sheets may have no trailing section.
- **Read the library symbol's pin coordinates before drawing wires** - wire ends must land exactly on pin ends (a
  0.25 mm miss shows up only as `unconnected_wire_endpoint`). Keep everything on the 1.27 mm grid.
- Power symbols set net names by their Value; renaming a power net = editing the power symbols' Value plus the board's
  `(net "...")`. ERC wants a driver on power nets fed through passives: add `PWR_FLAG`.
- Net ties (`NetTie_2`): `in_bom no`, `in_pos_files no`.
- **Verify every schematic edit by exporting the netlist** (`kicad-cli sch export netlist --format kicadxml`) and
  asserting the new refs and their connections. `kicad-cli sch upgrade --force sheet.kicad_sch` also catches parse
  failures ("Failed to load schematic").
- Regenerate from the committed sheet every time (`git show HEAD:sheet > sheet; python gen.py`), never on top of a
  previous run, and diff all `(text ...)` items against HEAD afterwards to catch accidental overwrites.

## Libraries

- Project libraries go in the project `fp-lib-table` / `sym-lib-table` with `${KIPRJMOD}` paths so the project opens
  on any machine. Copy parts that live only in a user's global or PCM libraries into project libraries under the same
  nickname (no references change).
- A footprint's library nickname must be in the footprint id (`MyProject:Name`); a missing or wrong nickname
  (`EasyEDA:` from an import) shows as `footprint_link_issues`.
- `kicad-cli sym upgrade` re-sorts symbols alphabetically - a large but harmless diff.

## Lock files

KiCad writes `~name.kicad_pcb.lck` (and `.kicad_sch.lck`, `.kicad_pro.lck`) while a file is open. kicad-cli can leave
stale ones behind after DRC or render runs; delete them when no editor is running (in zsh quote the name:
`rm ./'~name.kicad_pcb.lck'`, or `~name` is read as a user's home directory).
